# Пасьянс «Паук» — требования и решения

Сводка всех требований и принятых решений по проекту (сессия 11.11.2026).
Цель: личный офлайн-клон игры https://razlozhi.ru/patience-spider для iPad (iOS).

## 1. Вариант игры
- Только «Паук» в одну масть (пики). Выбора сложности нет.
- Колода: 104 карты = 8 комплектов пик A–K.

## 2. Правила (как в оригинале)
- 10 колонок на поле, колода (сток) — 50 карт, 5 сдач по 10.
- Цель — убрать все карты с поля.
- Карту можно положить на карту на единицу старше (без учёта масти) вместе с картами, лежащими на ней.
- Перетаскивать можно только убывающую последовательность одной масти.
- В пустую колонку можно положить любую карту/последовательность.
- Последовательность K→A одной масти автоматически убирается с поля в «дом» (левый нижний угол, стопки внахлёст).
- Если хотя бы одна колонка пустая, сдавать новый ряд нельзя — у колоды на 3 с показывается сообщение «Если хотя бы одна игровая ячейка свободна, новый ряд карт выкладывать нельзя.», пустые колонки подсвечиваются.
- Открытая верхняя карта колонки переворачивается автоматически после хода.

## 3. Тасовка и раздача (как в оригинале)
- Тасовка Фишера–Йетса со случайным сидом (crypto.getRandomValues); сид хранится, чтобы «Начать заново» давало ту же раскладку.
- Начальная раздача: 54 карты по одной, по кругу через все 10 колонок (первые 4 колонки получают 6 карт, остальные 5). Последние 10 сданных карт лежат лицом вверх.
- Анимация: все карты сначала в колоде рубашкой вверх, затем вылетают по одной в порядке раздачи.
- Сдача из колоды: по одной карте в каждую колонку слева направо, с анимацией, лицом вверх.
- Колода отображается одной стопкой в правом нижнем углу, группы по 10 карт со смещением.

## 4. Управление
- Только перетаскивание (drag & drop пальцем/мышью). Тап/клик по карте НЕ переносит её автоматически.
- Тап по колоде — сдать ряд.
- Клавиатура (если подключена): ⌘Z/Ctrl+Z — отмена, пробел — сдача.

## 5. Интерфейс
- Верхняя тёмная панель (#181818): название «Пасьянс «Паук (одна масть)»» и блок с градиентом #3e3a87→#2f2b74:
  - «Счётчик ходов» — каждый ход, сдача и отмена увеличивают счётчик на 1 (как в оригинале);
  - «Ваш рекорд» — наименьшее число ходов в выигранной партии (хранится локально).
- Счёт, таймер и общая статистика — убраны.
- Панель инструментов на сукне: «Новая игра», «Начать заново», «Отменить ход», «Подсказать ход» (круглые тёмные иконки + подписи).
- Подсказка: подсвечивает источник и цель хода, повторное нажатие — следующий вариант. Если ходов на поле нет, но можно сдать — подсвечивает колоду.
- Нет доступных ходов (и сдать нельзя): кнопка подсказки становится неактивной, текст «Нет доступных ходов», перечёркнутая лампочка (как в оригинале). Сбрасывается после любого действия.
- Подтверждения «Новая игра» (если партия начата) и «Начать заново» — во встроенных окнах.
- Победа: окно «Пасьянс разложен!» с числом ходов и рекордом + анимация прыгающих карт.

## 6. Внешний вид
- Цвет сукна как в оригинале: #2c733b, затемнение сверху (rgba(0,0,0,.3) → 0) и лёгкая шумовая фактура.
- Рубашка: гамма оригинала — синий #4454b4, белая кайма, светлая решётка (#ccd4ec / #ecf4fc), ромб в центре.
- Лицевые стороны: набор «Vector Playing Cards 2.0» © 2015 Chris Aguilar, LGPL 3.0. Пропорции карт 63×88 мм, прозрачные скруглённые углы.
  - Источник: https://commons.wikimedia.org/wiki/File:Color_52_Faces_v.2.0.svg (Wikimedia Commons; проект автора — http://sourceforge.net/projects/vector-cards/).
  - Локальная копия исходника: `project/Color_52_Faces_v.2.0.svg`.
- J, Q, K — без изменений из набора Aguilar.
- A–10 пересобраны из глифов Aguilar с пропорциями оригинального сайта (сетка 142×192), скрипт `compose.py`:
  - индекс достоинства: высота 24/192, слева сверху (x 8, y 8; у туза x 4, ширина 22; у «10» x 6, ширина 18);
  - маленькая масть под индексом: 18×20 в точке (6, 38);
  - пипы 30×30; колонки x = 30 / 56 / 82, верхний ряд y = 20, нижний y = 142, промежуточные ряды по раскладке оригинала; пипы ниже середины (центр > 105) перевёрнуты;
  - туз: большая пика 78×78 в точке (34, 50);
  - нижний правый индекс — поворот верхнего левого на 180°.
- Указание автора и лицензии LGPL сохранено комментарием в файле игры.

## 7. Сохранение состояния
- Автосохранение партии и истории ходов (для отмены) в localStorage; при повторном открытии партия продолжается.
- Рекорд хранится отдельно (ключ spider1.record).

## 8. Офлайн-работа на iPad
- Игра — один файл `index.html` в корне репозитория (все карты встроены). Он же работает и сам по себе, без сайта (например, в Documents на iPad): ссылки на иконки и офлайн-кэш в этом режиме просто не используются. Отдельный `spider.html` больше не ведётся.
- Пересылка HTML по почте не работает: быстрый просмотр iOS не выполняет JavaScript, Safari не открывает локальные файлы. Альтернатива для файла — приложение со встроенным браузером (например, Documents от Readdle).
- Основной способ — PWA на GitHub Pages:
  - репозиторий https://github.com/xzaa/spider (публичный, ветка main, корень);
  - сайт https://xzaa.github.io/spider/ (опубликован и проверен 11.11.2026);
  - файлы в корне репозитория: index.html, manifest.webmanifest, sw.js (кэш spider-<версия>, сначала сеть, при офлайне — кэш), icon-180/192/512.png (туз пик на зелёном), .nojekyll;
  - на iPad: Safari → «Поделиться» → «На экран „Домой“», первый запуск с интернетом; далее работает офлайн; новый push подтягивается при следующем запуске с сетью.

## 9. Версии и обновление (SemVer)
- Версия приложения хранится в одном месте — строка `const VERSION='X.Y.Z';` в `sw.js`; имя офлайн-кэша = `spider-X.Y.Z`. Начальная версия — 1.0.0.
- Любое изменение файлов сайта сопровождается подъёмом версии, иначе iPad может держать старый кэш.
- Правила SemVer для этого проекта:
  - **PATCH** (1.0.0 → 1.0.1) — исправления ошибок, правки внешнего вида и текстов, без новых возможностей;
  - **MINOR** (1.0.1 → 1.1.0) — новая возможность или заметное изменение поведения, сохранённая партия и рекорд остаются совместимыми;
  - **MAJOR** (1.1.0 → 2.0.0) — несовместимое изменение: меняется формат сохранения или ключи localStorage (`spider1.save`, `spider1.record`), из-за чего партия или рекорд сбрасываются.
- Порядок выпуска:
  1. правка `index.html` (и/или других файлов сайта);
  2. `python3 project/bump.py patch|minor|major` (без аргумента — показать текущую версию);
  3. `git add -A && git commit -m "vX.Y.Z: что изменилось" && git tag vX.Y.Z && git push --follow-tags`;
  4. на iPad — запустить игру с интернетом, новая версия подтянется сама.

## 11. Структура папки ~/spider
- Корень — сайт для GitHub Pages: index.html (вся игра), sw.js (версия и офлайн-кэш), manifest.webmanifest, icon-*.png, .nojekyll.
- `project/requirements.md` — этот документ.
- `project/Color_52_Faces_v.2.0.svg` — исходный лист карт (LGPL 3.0).
- `project/bump.py` — подъём версии по SemVer.
- `project/compose.py` — сборка карт A–10 (нужны растр листа `huge.png`, полученный `rsvg-convert -w 12000 Color_52_Faces_v.2.0.svg -o huge.png`, и `faces.json` с картами J/Q/K).
